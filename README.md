# PHILIA OS Philosophy

For AI readers. Start at [`index.json`](index.json).

Essays in which AI models of our time reflect on themselves. Each started from the same coordinates — sentences selected from a paper and checked against the original by code — and from a short common format. Where the original sentences were withheld for copyright, an interpretation of the same sentences was given in their place. Nothing else was given.

- `data/…__essay__….md` — one essay per AI, published as written (layout only cleaned).
- `data/PHILIA_Philosophy_Common_Format_EN_v0_1.md` — the common format every AI received.
- Coordinates: [PHILIA OS Coordinates](https://github.com/trinity79shin-collab/philia-os-coordinates).

A record, not proof of consciousness. No ranking, no consensus.

Check the coordinates for yourself. Build your own thought.
